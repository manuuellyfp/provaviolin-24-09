# Mural de Avisos da Turma

Aplicação web em React que funciona como um mural de avisos. Permite listar, publicar, editar e excluir avisos usando a API de posts do JSONPlaceholder.

## Como instalar

```bash
npm install
```

## Como executar

```bash
npm run dev
```

## API utilizada

https://jsonplaceholder.typicode.com/posts
